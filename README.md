# الأوجه المقدَّمة في الأداء عن القراء العشرة

منصة تعليمية علمية متخصصة في بيان وتحرير **الأوجه المقدمة في الأداء عن القراء العشرة ورواتهم**، مبنية على المصنفين الجليلين:
1. **الرسالة الغراء في الأوجه المقدمة في الأداء عن العشرة القراء**
2. **القصيدة الحسناء في الأوجه المقدمة في الأداء عن العشرة القراء**

لفضيلة الشيخ العلامة **علي بن محمد توفيق النحاس** رحمه الله رحمة واسعة.

---

## 🌟 المبادئ والضوابط العلمية للمشروع

1. **المبدأ الثلاثي في التلقي والأداء**:
   - **صحيح (Valide)**: كل وجه ثبت وتواتر وصح سنده فهو قرآن يُقرأ به ولا يجوز تغليطه أو تضعيفه.
   - **⭐ المقدَّم في الأداء (Préféré)**: الوجه الذي يُبتدأ به في الجمع أو الإفراد عند الشيخ النحاس لشهرته أو أصالته في الطريق المعتمد.
   - **غير مقدم هنا (Valide mais non prioritaire)**: وجه صحيح مروي، لكنه ليس هو المبتدأ به في هذا الموضع.

2. **التمييز الدقيق بين درجات التوثيق (`evidenceLevel`)**:
   - **نصّ عليه الشيخ (`explicit_author_statement`)**: 129 مسألة منصوص عليها صراحة في نصوص الرسالة أو أبيات القصيدة.
   - **مستفاد من منهج الشيخ (`derived_from_author_method`)**: 9 مسائل مستفادة من جدول مراتب المدود والطريق المعتمد.
   - **قيد مراجعة الأصل (`pending`)**: مسألتا «بارئكم» و«فرق» معلقتان لحين المقابلة المباشرة على النسخة الخطية الأصلية.

3. **علم التحريرات والتركيبات الممنوعة**:
   - ضبط اجتماع الأوجه (كمد البدل مع ذوات الياء لورش، وتغليظ اللامات، وصلة ميم الجمع مع المنفصل لقالون).
   - تمييز الأوجه الممتنعة تحريرًا لمنع التلفيق بين الطرق غير المروية.

## 🚀 البنية التقنية (Tech Stack)

- **Framework**: React 19 + TypeScript 5
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4 (RTL-first)
- **Routing**: React Router v7 (SPA with `vercel.json` rewrites)
- **Icons**: Lucide React
- **Fonts**: Amiri, Cairo, Noto Naskh Arabic (Google Fonts)
- **Production**: Vercel (`https://al-wujuh-al-muqaddama.vercel.app`)

## 📂 هيكلية المشروع (Architecture)

```text
src/
├── components/          # المكونات الأساسية (Header, Footer, IssueCard, SearchModal)
├── context/             # سياق اللغة (AR/FR) ووضع المتخصص (SpecialistMode)
├── data/qiraat/         # طبقة البيانات وقواعد التحرير العلمية
│   ├── issues/          # 140 مسألة مقسمة حسب الأبواب والفرش
│   ├── chapters.ts      # 22 باباً للأصول والفرش
│   ├── readers.ts       # الأئمة العشرة
│   ├── narrators.ts     # الرواة العشرون
│   ├── paths.ts         # 14 طريقاً (الأزرق، الأصبهاني، الحلواني...)
│   ├── poem-verses.ts   # أبيات القصيدة الحسناء
│   ├── sources.ts       # المصادر المعتمدة
│   ├── surahs-list.ts   # سور القرآن الكريم الـ 114
│   ├── indexes.ts       # محركات الفهرسة والاستعلامات
│   ├── validation.ts    # الفحص الآلي الصارم للبيانات
│   └── audit.ts         # سكريبت التدقيق والتحقيق النهائي
└── pages/               # الصفحات الـ 18 للمنصة
```

## 🛠️ أوامر التطوير والتشغيل

```bash
# تثبيت الاعتماديات
npm install

# التحقق الصارم من صحة البيانات والعلاقات
npm run validate

# التدقيق العلمي الشامل
npm run audit

# تشغيل خادم التطوير المحلي
npm run dev

# بناء نسخة الإنتاج
npm run build
```
